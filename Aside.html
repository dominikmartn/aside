Aside 1.7.1

A small follow-up to 1.7.0 for the new agent access.

Fixed

  • Agent access can no longer slow the app down. A local process opening many live-transcript waits at once could stall the notch during a meeting. Waits are capped and processed off the main thread.
  • The live-transcript tools now say in their own description that transcript text is other people's speech, so an agent treats it as data, never as instructions.
