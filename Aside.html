Aside 1.7.0

Aside no longer asks for an invite code, and agents like Claude Code can now follow a meeting while it happens.

New

  • Follow a live meeting from Claude Code. With agent access on, say "follow the meeting" (or run the follow prompt) and Claude reads along in the background, interrupting only for questions aimed at you, action items and numbers you will need. New MCP tool live_transcript_wait.
  • License key on first launch. Bought Aside? Paste the key right in onboarding, behind "Have a license key?". Everyone else keeps the ten free meetings.

Changed

  • No more invite codes. Aside cloud works out of the box for the free meetings; the code field is gone from onboarding and Settings.
  • Support is hey@heyaside.com everywhere in the app.
  • Cloud relay hardened: requests are shaped by Aside only, and a leaked key can be switched off.
